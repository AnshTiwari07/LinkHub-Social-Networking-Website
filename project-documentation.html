🗄️ Database Design

Users Table

CREATE TABLE users ( id INT AUTO_INCREMENT PRIMARY KEY, full_name VARCHAR(255) NOT NULL, email VARCHAR(255) UNIQUE NOT NULL, password VARCHAR(255) NOT NULL, age INT NOT NULL, profile_picture VARCHAR(255), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP );

Posts Table

CREATE TABLE posts ( id INT AUTO_INCREMENT PRIMARY KEY, user_id INT NOT NULL, description TEXT NOT NULL, image VARCHAR(255), likes INT DEFAULT 0, dislikes INT DEFAULT 0, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE );

Post Reactions Table

CREATE TABLE post_reactions ( id INT AUTO_INCREMENT PRIMARY KEY, post_id INT NOT NULL, user_id INT NOT NULL, reaction_type ENUM('like', 'dislike') NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE, UNIQUE KEY unique_reaction (post_id, user_id) );

🚀 Getting Started

Prerequisites

  • PHP 7.4 or higher
  • MySQL 5.7 or higher
  • Web server (Apache/Nginx)
  • Modern web browser

Installation Steps

  1. Clone/Download: Place all files in your web server directory
  2. Database Setup: Import the schema from sql/schema.sql
  3. Configuration: Update database credentials in config/database.php
  4. Permissions: Ensure uploads/ directory is writable
  5. Access: Navigate to index.html in your browser
Note: Make sure to update the database connection settings in config/database.php to match your MySQL configuration.

🎯 Key Implementation Details

Object-Oriented Programming

The project follows OOP principles with well-structured classes:

  • User Class: Handles user registration, authentication, and profile management
  • Post Class: Manages post creation, deletion, and reaction tracking
  • Database Class: Centralized database connection management

Security Implementation

  • Password Hashing: Using PHP's password_hash() with bcrypt
  • SQL Injection Prevention: All queries use prepared statements
  • File Upload Security: Type and size validation for uploaded files
  • Input Sanitization: All user inputs are properly sanitized

AJAX Implementation

  • Post Management: Add and delete posts without page reload
  • Real-time Reactions: Like/dislike updates instantly
  • Form Validation: Client-side validation with server-side backup

📱 Responsive Design

The application is fully responsive and works seamlessly across all devices:

  • Mobile First: Designed for mobile devices first, then enhanced for larger screens
  • Flexible Layouts: CSS Grid and Flexbox for modern, flexible layouts
  • Touch Friendly: Large buttons and touch targets for mobile users
  • Cross Browser: Compatible with all modern browsers

🔧 Customization

The project is designed to be easily customizable:

  • Styling: Modify assets/css/style.css for custom themes
  • Functionality: Extend classes in classes/ directory
  • Database: Add new tables and relationships as needed
  • Features: Add new AJAX endpoints in api/ directory
